# 사용자 안내

[English user guide](USER-GUIDE.md)

이 안내는 DarkReNamer의 한국어 네이티브 인터페이스를 설명합니다. 운영 체제와 파일
시스템의 지원 범위는 [README](../README.ko.md#지원-환경)를 확인하세요. 파일 변경과
복구의 기준은 [안전 모델 — 영어](../SAFETY.md)입니다.

## 항목 추가와 미리보기 확인

관리자 권한 없이 DarkReNamer를 실행합니다. **파일 > 파일 추가...**로 지원 범위
안의 항목을 목록에 추가하세요. 이름 변환을 선택한 뒤 **변경 적용**을 누르기 전에
제안 이름과 상태 열을 모두 확인하세요. 마지막 확인 창은 취소가 기본 선택입니다.
변경 내용을 확인한 뒤에만 승인하세요.

파란색 강조는 변경 예정 이름, 주황색은 경고, 빨간색은 차단된 이름을 나타냅니다.
색을 구분하지 않아도 상태 문구로 같은 의미를 확인할 수 있습니다. 행 하나를
선택하고 **보기 > 선택 항목 진단...**을 열면 전체 설명, 원본·제안 경로 및
수정 방법을 볼 수 있습니다. 이 진단은 동기화된 모델 미리보기이며 실제 파일
시스템의 현재 점유 상태를 검사하거나 변경 적용을 승인하지는 않습니다.

## 이름 또는 경로 저장

**파일 > 내보내기 > 변경 후 이름 목록 저장...**과
**파일 > 내보내기 > 현재 경로 목록 저장...**은
BOM이 있는 완전한 UTF-16LE 텍스트 파일을 씁니다. 지원하는 로컬 NTFS 폴더에서
아직 사용하지 않은 새 파일 이름을 선택하세요. 기존 파일은 덮어쓰지 않습니다.
저장이 끝나기 전에 다른 프로세스가 그 이름의 파일을 만들면 내보내기가
실패하며 기존 파일은 그대로 남습니다. 새 파일에는 선택한 폴더의 일반적인
상속 권한이 적용됩니다. 내보낸 내용을 비공개로 유지하려면 비공개 폴더를
선택하세요.

## 텍스트 가져오기, 취소 및 창 닫기

**파일 > 변경 후 이름 목록 가져오기...**는 텍스트 파일의 제안 이름을 목록
순서대로 가져옵니다. **파일 > 경로 목록에서 추가...**는 텍스트 파일에 적힌
경로의 항목을 목록에 추가합니다. 가져올 텍스트 파일을 고르는 작업과 실제로
이름을 변경할 항목의 파일 시스템 지원 범위 검증은 별개입니다. 가져오기
선택기에서는 네트워크 또는 공급자 위치의 텍스트 파일도 선택할 수 있지만,
이름 변경 지원 범위는 로컬 NTFS로 제한됩니다. 가져오기 파일은 작업 스레드가
읽으며, 공급자의 I/O 응답에는 정해진 완료 시간이 없습니다.

취소 요청은 즉시 완료를 뜻하지 않습니다. 가져오기 작업이 끝날 때까지 창
닫기와 새 작업이 대기할 수 있습니다. 취소를 요청한 뒤 늦게 읽힌 결과는
목록에 적용하지 않습니다. 대기 상태를 해제하려고 저널이나 잠금 파일을
이동·편집·삭제하지 마세요.

## 대상 폴더 지정 또는 초기화

**편집 > 대상 폴더 > 모든 파일의 대상 폴더 지정...**을 사용하면 일반 파일을
같은 로컬 NTFS 볼륨에 이미 존재하는 디렉터리로 옮기도록 제안할 수 있습니다.
목록에 디렉터리가 하나라도 있으면 이 명령을 사용할 수 없습니다. 폴더를
선택한 뒤 다시 계산된 경로, 충돌, 상태 및 변경 적용 가능 여부를 확인하세요.

**편집 > 대상 폴더 > 대상 폴더 미리보기 초기화**는 제안 이름을 유지하면서
대상 폴더를 원래 부모 폴더로 되돌립니다. **편집 > 이름 미리보기 초기화**는
대상 폴더 제안을 유지하면서 제안 이름을 원래 이름으로 되돌립니다. 두
명령은 제안만 변경하며 이미 완료된 파일 작업을 되돌리는 Undo가 아닙니다.

## 제안 적용

모든 행을 확인한 뒤 **변경 적용**을 선택하세요. DarkReNamer는 최종 확인
창을 표시하기 전에 원본과 부모의 식별자, 이름, 대상 및 선택한 지원 범위를
다시 열어 검증합니다. 확인 창은 이름만 변경, 이동만 수행, 두 작업을 함께
수행하는 경우를 구분하며 기존 대상은 덮어쓰지 않는다고 알립니다.

최종 확인을 취소하면 파일은 변경되지 않습니다. 실행이 시작된 뒤에는 각
파일 작업 단계가 완전히 끝난 경계에서만 취소를 확인하며, 저널을 사용한
롤백이 시작될 수 있습니다. 진행 창은 실제로 일어난 결과를 표시합니다.
취소 요청을 받았다는 표시는 롤백이 이미 끝났다는 뜻이 아닙니다.

## 모양

**보기 > 테마** 메뉴에서 **시스템 설정**, **밝게**, **어둡게** 모드를
선택할 수 있습니다. 기본값인 시스템 설정은 Windows 앱 색 설정을 조회할
수 있을 때 그 설정을 따릅니다.
강제 색 모드 또는 고대비 설정 조회 불가 상태에서는 저장된 모양 설정보다
Windows 렌더링이 우선하며 사용자 지정 색은 적용되지 않습니다.

DarkReNamer의 밝게·어둡게 팔레트는 기본 작업 화면, 명령 버튼과 도구 설명,
목록 머리글과 정보 설명, 상태 영역, 메뉴, 앱이 소유한 입력 창 및 상세 모양
설정 창에 적용됩니다. 네이티브 시스템·강제 색 화면, 파일 대화상자 및 최종
확인 TaskDialog는 Windows가 렌더링합니다.

앱이 소유한 글꼴은 Windows 텍스트 크기 설정과 모니터 DPI를 함께 반영합니다.
텍스트 크기 설정을 조회할 수 없으면 일반 시스템 글꼴 크기를 유지합니다.
Windows가 소유한 TaskDialog의 글자 크기는 운영 체제의 동작을 따릅니다.

파일 목록의 스크롤, 입력 및 접근성은 네이티브 Windows ListView가
담당합니다. 앱의 어둡게 팔레트에서는 네이티브 스크롤바의 모양을 그 팔레트로
다시 그립니다. 시스템·강제 색 모드나 사용자 지정 그리기가 불가능한
경우에는 Windows 렌더링을 유지합니다. 상세 모양 설정 창은 스크롤되는
본문에 별도로 어두운 네이티브 테마를 요청하며 사용할 수 없으면 시스템
렌더링으로 돌아갑니다. 네이티브 포커스와 선택 상태는 유지됩니다.

## 상세 모양 설정

**보기 > 모양 설정...**에서 의미에 따른 밀도·강조 표시 설정, 구분선, 변경된
이름의 배경 강조 및 빈 목록의 안전 안내 표시를 설정할 수 있습니다. 작업
영역이 좁거나 시스템 글꼴이 크거나 DPI가 높아 본문을 스크롤해야 할 때에도
초기화, 저장 및 취소 버튼은 하단에 고정됩니다.

모양 설정은 표시만 바꿉니다. 제안 이름, 모델 버전, 변경 적용 승인, 저널
권한, 파일 변경·복구 잠금 또는 복구 데이터는 바꿀 수 없습니다.

열 표시 및 모양 설정은 `%LOCALAPPDATA%\DarkReNamer`에 저장됩니다. 포터블
실행 파일 옆에 설정 파일은 필요하지 않지만, 실행 파일을 옮기거나 교체해도
설정은 현재 Windows 사용자와 연결됩니다. 설정을 읽거나 쓰는 데 실패하면
안전한 기본 표시 설정을 사용합니다.

## 중단 뒤 복구

시작할 때 보존된 저널이 발견되면 선택한 파일을 변경하기 전에 복구 잠금
상태로 열릴 수 있습니다. 유효한 활성 저널이 하나 있으면 복구 창은 취소를
기본 선택으로 표시합니다. 사용자가 명시적으로 확인해야 현재 식별자를
대조하고 역순 롤백을 시도합니다.

활성 저널과 후보 저널이 함께 있거나 내용이 손상·절단되었거나 승격 결과가
불확실한 등 모호한 상태가 표시되면 변경 적용 잠금을 유지하고 저널 증거를
보존하세요. 저널이나 잠금 파일의 이름을 바꾸거나 옮기거나 편집하거나
삭제하여 잠금을 우회하지 마세요. 표시된 진단을 보고하세요.

진단 내보내기는 보존된 저널 증거를 새 파일로 복사하며 기존 파일을
덮어쓰지 않습니다. 내보낸 자료에는 개인 경로나 파일 시스템 식별자 정보가
들어 있을 수 있으므로 비공개로 보관하세요. 이 저장소에 문제를 보고할 때는
표시된 단계, 구조화된 종류, 네이티브 코드, 코덱 프레임 및 관찰된 크기를
전달하세요. 원본 DarkNamer 관리자에게 보고하지 마세요.

저널 상태, 정리 규칙 및 손상된 증거 처리 기준은
[시작 시 복구 및 손상된 증거 — 영어](../SAFETY.md#startup-recovery-and-corrupt-evidence)를
참조하세요.

## 알려진 제한

- 프로그램 인터페이스는 영문·일문 README에서 이 안내로 들어오더라도
  한국어입니다.
- 네이티브 시스템·강제 색 화면, 파일 대화상자 및 최종 확인 TaskDialog는
  Windows가 그리므로 앱의 밝게·어둡게 팔레트와 다를 수 있습니다. 스크롤바의
  네이티브 동작과 어둡게 모드의 표시 방식은 [모양](#모양)을 참고하세요.
- 모델 미리보기는 현재 파일 시스템 상태를 보증하지 않습니다. 변경 적용은
  언제나 새로 검증합니다.
- 제안 초기화는 파일 시스템의 Undo가 아닙니다.
- 볼륨 간 이동, 디렉터리 이동, 대상 폴더 생성, 기존 대상 교체, 폴더 병합,
  NTFS 외 파일 시스템, 네트워크·장치 경로, 대소문자 구분 디렉터리, 관리자
  권한 실행 및 재분석 지점 통과는 지원하지 않습니다.
- 자동 검사는 사람의 시각 평가, 포괄적인 접근성, 실제 IME·Explorer 조작,
  물리적 저장 장치와 전원 손실 상황의 동작을 입증하지 않습니다.
