# DarkReNamer

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md)

DarkReNamer は [DarkNamer](https://github.com/nanpuhaha/DarkNamer) の非公式な
コミュニティ管理の Rust 移植版であり、GitHub フォークです。DarkNamer
08.02.10 の名前変換とコマンド動作を互換対象としていますが、独自の安全
モデルとインターフェースを使用します。`darkwalker`、Seo Jang-won、または
上流リポジトリ管理者による公式リリースではありません。

アプリケーションのネイティブ Windows インターフェースは韓国語です。この
README の英語版と韓国語版は、アプリケーションがそれらの表示言語にも対応
していることを意味しません。

## ダウンロード

[GitHub Releases](https://github.com/PiesP/DarkReNamer/releases) から最新の
ポータブルなプレリリースとチェックサムをダウンロードしてください。実行
可能な製品は、インストール不要の `DarkReNamer.exe` 1 ファイルです。現在の
ビルドは署名されていません。使用前に
[配布ポリシー（英語）](DISTRIBUTION.md#current-unsigned-handoff)を読み、同梱の
チェックサムと来歴を検証してください。

ソースは [DarkReNamer リポジトリ](https://github.com/PiesP/DarkReNamer)で管理
されています。自分でビルドする場合は
[開発ガイド（英語）](DEVELOPMENT.md)に従ってください。

## 対応環境

DarkReNamer は x64 版 Windows 11 以降を正式にサポートします。Windows 10
でも動作する可能性はありますが、テスト対象でも正式サポート対象でも
ありません。

v0.1 のファイルシステム対応範囲は、再解析ポイントを通過しない、大文字と
小文字を区別しないローカル NTFS ディレクトリ上で、管理者権限なしで実行
する場合です。

| 操作 | 対応範囲 |
| --- | --- |
| ファイルとディレクトリの名前変更 | 同じ親ディレクトリ内 |
| ファイルの移動 | 通常ファイルのみ。同じローカル NTFS ボリューム上の既存ディレクトリへ移動 |

ネットワークまたはデバイスパス、NTFS 以外のファイルシステム、大文字と
小文字を区別するディレクトリ、管理者権限での実行、再解析ポイントの通過、
ボリュームをまたぐ移動、ディレクトリの移動、移動先ディレクトリの作成、
既存項目の置換、フォルダのマージには対応していません。実行時にもこの境界を
確認し、条件を満たさない場合は安全側に停止します。

## クイックスタート

1. 管理者権限を使わずに `DarkReNamer.exe` を起動します。
2. **파일 추가...**（ファイルを追加）を選び、対応範囲内の項目を追加します。
3. 名前変換を選び、提案された名前と Status 列をすべて確認します。ブロック
   された行は **보기 > 선택 항목 진단...**（表示 > 選択項目の診断）で理由を
   確認できます。
4. **변경 적용**（変更を適用）を選び、再検証された計画を確認して承認します。
   確認画面をキャンセルした場合、ファイルは変更されません。

対応範囲内で通常ファイルを移動するには、先に **편집 > 대상 폴더 > 모든
파일의 대상 폴더 지정...**（編集 > 対象フォルダ > すべてのファイルの対象
フォルダを設定）を使います。

## 安全性と復旧

- Safe v2 は実行直前に項目と親の ID を再確認し、変更前に永続的な Intent を
  記録し、既存の対象を置き換えない操作だけを実行します。
- プレビューは現在の提案を表示するものです。Apply の検証までは、実際の
  ファイルシステムを検証せず、変更も許可しません。
- **편집 > 모든 이름 변경 취소** は提案された名前だけをリセットします。
  ディスク上ですでに行われた変更を元に戻す機能ではありません。対象
  フォルダのリセットも提案だけを変更します。
- 操作が中断された場合やジャーナル状態が不確かな場合は、その後の Apply が
  ロックされることがあります。ジャーナル証拠を残し、次回起動時の復旧
  ウィンドウに従ってください。ジャーナルファイルの移動や削除でロックを
  回避しないでください。

変更と復旧の完全な契約は[安全モデル（英語）](SAFETY.md)にあります。外観、
ローカル設定、診断、復旧の操作方法は
[ユーザーガイド（英語）](docs/USER-GUIDE.md)を参照してください。

## 検証範囲の制限

リリース検証は、正確な候補実行ファイルに自動ソース検査と固定 Windows VM
プロファイルを結び付ける
[VM-Automated 契約（英語）](SAFETY.md#vm-automated-release-validation)で定義
されます。ポリシー文書自体は特定のキャンペーンの合格を示さず、この README
も VM キャンペーンの合格を主張しません。

VM-Automated v1 は、物理デバイス性能、物理的な電源喪失、VM リセットまたは
ストレージ障害、人による視覚確認または包括的な支援技術の受け入れ、実際の
IME および Explorer ドラッグ＆ドロップを対象としません。DarkNamer との
手動検証済みランタイム互換性も証明しません。過去の手動および物理的な
受け入れ要件は
[Windows 受け入れ履歴（英語）](docs/history/WINDOWS-ACCEPTANCE.md)に分けて
保存しています。
